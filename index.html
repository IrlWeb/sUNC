features

What makes this build different?

Unobfuscated by design

Every test is readable end-to-end. You can audit exactly what is checked and why — nothing hidden, nothing packed.

Full coverage

81 tests across 13 categories — from closures and debug to drawing, filesystem, signals and WebSocket.

Behaviour, not presence

Functions are actually invoked and their results asserted. A stub that merely exists won't pass — fake implementations get exposed.

Run only what you want

Set functionstotest to re-run a single check — e.g. ["filesys"] = true — instead of the whole suite.

Observability built in

Flip on printcheckpoints, printtesttimetaken or add a delaybetweentests pause — all via one config table.

Clear scoring

A summary block prints passed / failed / untested counts and a percentage score for the executor under test.

Single-file drop-in

One dependency-free Lua file. Paste it directly or load it via loadstring(game:HttpGet(...))() — nothing else to install.

Familiar config

Uses the same getgenv().sUNCDebug table as the original, so existing setups keep working without changes.
